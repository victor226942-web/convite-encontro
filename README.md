# Convite — Encontro

Página única de convite. `index.html` só redireciona (meta refresh) para `convite-encontro.html`, que tem o convite de fato.
`main.py` é o exemplo padrão do PyCharm (não usado).

## Rodar / publicar
Abra `index.html` em um servidor estático; ele leva ao convite. Publicável em qualquer hospedagem estática.
